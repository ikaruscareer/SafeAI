# ADR 0004 — Name and trademark strategy (neutral record)

- Status: accepted (operational, pending legal review)
- Date: 2026-09-12
- Context: the project uses the names "SafeAI" and "Know Your Agent
  (KYA)". No verified evidence exists that either is a registered
  trademark, and this repository makes no such claim.
- Decision: use "SafeAI" and "Know Your Agent (KYA)" consistently as
  project positioning pending review. Seek qualified legal advice before
  asserting registration, protection, or enforcement of any mark, and
  before any Corporate-edition naming or licensing decision that depends
  on it.
- Alternatives: claim protection without evidence (rejected: dishonest);
  rename preemptively without cause (rejected: churn without benefit).
- Consequences: docs and marketing must avoid ®/™-style assertions until
  review concludes; this ADR is revisited when advice arrives.
